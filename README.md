# Virtual Theater Website

## How to use
1. Extract this ZIP.
2. Open the `virtual-theater` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Click **Owner Portal** to open the admin area.

## Included pages
- index.html — Home page
- movie.html — Movie details
- player.html — Demo player
- admin/dashboard.html — Owner dashboard
- admin/upload.html — Upload UI
- style.css — All styling
- script.js — Search and demo interactions

## Important
This is a frontend demo. File uploads are only UI until you connect a real backend/storage service.
Only upload and stream content you own or are licensed to distribute.
